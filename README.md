# music.wordnspirit.com

陳曉東｜聖言音匠工作室 — songs site (pure static, text-only design).

- Generated by `build.py` (production build sets `MUSIC_VIDEO_BASE=https://media.wordnspirit.com/think-on-these-things`).
- Pages serves the HTML/CSS and the MP3; MV files (720p/480p) are served from Cloudflare R2 at media.wordnspirit.com.
- Deploy: Cloudflare Pages, framework None, output directory = repo root.
