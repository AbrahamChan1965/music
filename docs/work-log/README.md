# 工作日誌

聖言音匠音樂工作群的工作日誌。Abe 2026-11-26 下令：沒有工作日誌，將來會失憶。這裡是記憶，不是對話。

## 規矩

- 每天一篇：`docs/work-log/YYYY-MM-DD.md`。每篇五節：做了什麼、定了什麼、踩了什麼坑、新學了什麼、還開著什麼。沒工作的日子不寫。
- 只記事實，寫清出處（日期、檔案、deploy／commit 號）。不要憑印象編。
- 大文件（影片、音頻、模型權重）絕不進倉：走 R2＋Google Drive。倉裡只放文字、表、腳本。
- 教訓合集的工作版在 `~/workspace/music-videos/MV-製作教訓合集.md`，開工前讀那一份。倉裡的 `docs/LESSONS.md` 是記錄本，由每日工作日誌任務同步（快照，不作工作版）。
- 回顧文件是一次性的重建，不按日更；以後每逢大節點再寫一篇新的回顧。
- 每日任務成功靜默，失敗才回報。

## 目錄

- `2026-11-26-retrospective.md`：創建至今的回顧（創建日期、走了多久、坑的編號清單、避坑秘籍總表、還開著的事）。
- `2026-11-26.md`：當日日誌。
